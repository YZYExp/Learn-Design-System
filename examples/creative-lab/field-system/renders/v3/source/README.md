# 野序 / FIELD NOTES

野序是本书原创虚构的植物艺术画报。刊号07、2027夏刊、花展名称、日期、票务与场地均为演示文案，不是实际出版物或活动。画报内容讨论观看、绘画与编辑，不提供植物鉴定。

## 声音与阅读
亲近自然，但不假装学术标本。标题是邀请，正文具体、安静；图像的笔触可以密集，阅读区必须稳定。不要把字直接压进花瓣。

## 色彩与字型
paper #F4EEDC承载长文；plum #482C45负责大字、正文；moss #3E5947是图注、日期与页码。pink #E6C7C9是少量信息贴片，不铺满封面。白色不是主纸色。中文为离线Field Sans（Noto Sans SC），英文为离线Field Serif（URW P052）。中文大字保持平直，不模拟不存在的历史字体。

## 图像与裁切
只采用本地AI鸢尾画。封面可切去边缘，但不能同时切掉三朵花的中心；跨页可以放大花瓣褶皱，图注须说明局部。不要增加虚构拉丁学名、采集地或植物学图签。装饰最多一个小圆章或温粉标签，不叠加花环边框。

## 跨页规则
正文放在右页独立奶油区，不跨装订中缝。两栏均从左到右、由上到下。图注靠近图像下缘，低于正文视重；正文与图注均在页脚横线以上结束。前景图像与文字至少留space-40，书脊侧不放必须辨认的花蕊。

## 组件
FieldNotes.Masthead、EditorialCaption、EventBadge返回实际DOM；preview调用它们，Cover组合三个组件。组件源码、类型与预览在components中。

## 安装与更新
通过原生design-systems安装接口，field-canvas获得tokens.json与字体快照，canvas.json记录来源和版本。快照不自动跟随本项目；token修改后在画布设计系统面板重新安装。画板文字与视觉属性是可编辑标记。source/build_field.py重建初版，人工编辑后不要无意运行覆盖。

## 素材身份
品牌、编辑文案与版式为本书原创；鸢尾图为AI生成教学素材。Noto Sans SC与URW P052字体遵循fonts内许可，不改称本书原创。
