# 附录三｜带着一页纸，完成自己的第一套规则

这份工作纸可以手抄，也可在文字或绘图软件中填写。

## 一、明确任务与使用条件

项目名称：________。使用者：________。他在什么地点、距离、光线和时间压力下使用：________。最重要的动作或信息：________。我明确暂不解决的事：________。

不要只写“年轻、时尚、有品质”。将它改为可观察目标，例如“参观者在路口能找到下一展区”“手机报名时知道是否提交成功”“三种尺寸的海报都保留名称和日期”。审美目标可以保留，但不能代替任务。

## 二、建立小而清楚的规则

| 层次 | 我要写的内容 | 对照检查 |
| --- | --- | --- |
| 目的 | 一句可解释的目标 | 做得漂亮但任务失败时，能否指出问题？ |
| 共同词汇 | 2—4种形、1—2类字体、少量颜色角色 | 去掉logo还能认成一家吗？ |
| 组合 | 主次、间距、对齐与相邻关系 | 换内容后关系是否仍成立？ |
| 适配 | 窄屏、小尺寸、黑白与不同材料 | 哪些改变合法，理由是什么？ |
| 交互或操作 | 输入、过程、结果、失败或实体操作方式 | 使用者是否知道下一步？ |
| 维护 | 文件位置、负责人、版本和反馈入口 | 别人能否找到正确的一版？ |

先画三个不同媒介实例，至少包含一个信息量较大的困难样本。只用最漂亮的简单样本检查，通常会高估规则的能力。

## 三、做五种有目的的破坏

第一，把标题变成原来的两倍长。第二，拿走彩色，只保留黑白。第三，把尺寸缩小一半。第四，换成你没有设想过的内容。第五，让没有参与的人按你的说明继续做。

每次记录输入、出现的问题、修改的规则与重新验证的结果。单独调整一个实例，未必能解决其他实例中的同类问题；是否修改通用规则，则要结合问题出现的频率和实际需求判断。

## 四、怎样选择实现工具

起步可用纸笔研究结构；矢量工具处理轮廓、标识与印刷版式；位图工具处理绘画、照片和材质；排版工具适合长书与印前；三维工具帮助推敲体积、镜头与空间；代码适合参数化、数据图、批量变化和检查。具体产品的功能、价格与许可会变，先按任务类别选，再核对当前官方说明。

本书工程以分章 Markdown 保存正文，Python 绘制精确教学图并生成 PDF，Git 记录修订。在线阅读站由 MkDocs Material 从同一份正文和配图构建；可编辑画板与设计系统另存于原创工坊目录。正文、图形和版式因而可以分别修改，并通过重新构建同步到阅读成品。

应保存正文、规则、可编辑源文件、素材出处、生成提示词、依赖与构建命令。这些输入既能解释设计决定，也便于他人继续制作和重建成品；截图可作为外观参考。

## 五、一次20分钟的复盘

用五分钟回看任务，用五分钟比较三个媒介，用五分钟查看一个失败样本，最后五分钟写下下一版只改的一条规则。一次改太多，很难知道哪项改变真正有帮助。

复盘记录分为三部分：已有证据支持的三项判断，仍需测试的两项问题，以及当前保留的一项取舍。每项都指向具体实例或使用结果，便于下一轮修改时回查。
