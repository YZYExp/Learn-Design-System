# 全文校订标准

适用于《设计的语法》的正文、导读、附录和阅读入口。依据既定写书要求与2026年10月22日的全文校准要求整理。以下为本项目执行标准，不是对用户原话的逐字转录。

## 叙述与教学

- 直接说明对象、条件、关系与结果。删去没有新增信息的开场、铺垫和总结。
- 将作者设问后立即回答的段落改为连贯陈述；问题确实要求读者观察、比较或操作时保留。
- 用位置、比例、间距、材料、状态、任务等具体内容解释设计选择，减少“真正”“关键”“高级”等没有判据的评价。
- 避免反复使用“不是……而是……”、口号式对偶、拟人化结论和聊天式提醒。确需区分相邻概念时，明确写出各自范围。
- 每节保留必要的事实、案例、因果解释与操作条件。校订不能将正文压缩为摘要，也不能以删去所有问号代替编辑。
- 练习说明写清输入、操作和观察对象。保留探索空间，不将参考分析写成唯一正确答案。

## 证据与一致性

- 保留作品名称、作者、年代、材料与机构归属，维持事实与就近来源的对应关系。措辞调整不扩大来源支持的结论。
- 保留原作、分析图、教学图、生成图与原创作品的身份说明；将必要的使用边界集中说明，减少反复辩解。
- 稳定章节文件名、主标题、图片路径和图号。对小节标题的修改须通过站内锚点检查。
- 保留案例覆盖、图片、代码示例与练习所需内容；逐章检查，不能仅靠批量替换词语。
- PDF、网站、目录和当前页码索引由同一份已校订正文构建。旧版页码索引作为历史记录保留，明确与当前版本区分。

## 交付检查

1. 对比校订前后的37份主稿，核对章级标题、全部图片顺序、链接目标与代码块。
2. 检查修改后的论证、术语与跨章衔接，复查残留的机械设问、重复否定和空泛收尾。
3. 重建全书PDF，检查缺字、书签、链接、图注分页、页边界和全部187次配图放置。
4. 渲染全书缩略图，查看代表性正文、表格、代码与原创作品页面。
5. 重建阅读站，检查所有站内文件和锚点；推送后核验PDF与Pages两条CI。

## 本轮修订示例

- 导读“读完后，应该能做什么”改为“学习内容与阅读路线”，以具体学习对象组织段落。
- “不要把本书当风格速成处方……我们要追问的是……”改为直接说明形式辨认所需的历史语境、使用条件与取舍。
- 附录的三段自问自答改为三个概念的应用边界；旁读表和工作纸中的观察问题仍保留。
- 附录中旧的网站说明更新为从同一份主稿构建在线阅读站，避免版本说明与已发布成品矛盾。
