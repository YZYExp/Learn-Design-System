# 6.0主线重编记录

6.0沿用5.1已经校订的书稿、真实作品和原创工坊，调整全书的学习顺序、案例位置及跨章衔接。源文件保留原名，显示章号按新的阅读顺序连续编排。

## 学习主线

观察作品 → 提炼视觉关系 → 适配不同媒介 → 建立可复用规则 → 检验与维护。

| 篇 | 新章号 | 任务 |
| --- | --- | --- |
| 第1篇 · 看懂一件作品 | 01—04 | 用任务、视觉关系、颜色与网格建立观察方法。 |
| 第2篇 · 形成一种视觉语言 | 05—11 | 从图像到装饰、几何、文字和生成规则，理解视觉选择如何组合。 |
| 第3篇 · 组织传播与阅读 | 12—17 | 将同一套判断用于品牌、海报、广告、演示、书籍和画报。 |
| 第4篇 · 进入材料、身体与空间 | 18—23 | 让视觉规则经受材料、包装、器物、身体和场所的约束。 |
| 第5篇 · 处理时间、操作与状态 | 24—27 | 从时间脚本走到交互，用语义角色、Token与组件组织变化。 |
| 第6篇 · 完成、检验与维护 | 28—33 | 完成综合项目，与真实案例比较，再安排协作、修订与练习。 |

插画与摄影提前至视觉语言篇，生成方法接在历史与形式选择之后；品牌、海报、广告、PPT、书籍、画报组成连续的传播与阅读篇；材料、包装、产品、服装、空间、导视组成实体媒介篇；动效与数字设计按时间、操作、语义角色和状态推进。综合项目放在相关方法之后，最后再讨论比较、治理与持续练习。

书籍章关注长文、条目、层级和检索；画报章关注选题、图片叙事、图注与期刊流程。两章各自保留适用范围，避免把图片编辑与长文排版混为一套模板。

## 连续项目与独立工坊

“岸线设计周”是贯穿全书的教学虚构项目。第一篇确定受众、信息与海报、册页、导视、纸袋、手机预约等交付任务；后续章节逐步积累视觉规则和媒介约束，第28章回收前文记录，完成整套系统与检验。

第29章的折光、野序、隙间保持三套独立原创项目的身份，用于展示AI视觉提案、无字素材、可编辑Canvas和设计系统如何配合。它们与岸线项目形成对照，不被改称为同一活动的成品。

## 图片与可追溯性

5.1的178张独立图像全部保留，新增 `assets/images/book-learning-map.png`，形成179张独立图像。三处重复使用的品牌图片合并到完整案例中，共185次配图使用；减少重复放置不代表删去独立图像。

## 目录、URL与构建

`book.json` 是唯一的阅读顺序清单；网站导航、首页目录、前后章导航和PDF依序构建。`scripts/book_manifest.py` 校验安全路径、连续编号和全量源文件覆盖；`scripts/check_structure.py` 检查显示标题、案例目标与图片引用。

源文件和URL slug保持不变。例如 `chapters/23-image-making.md` 现在显示为第05章，但不改为新的文件名。网页构建保留旧数字章节锚点，原第32章保留六个案例和总结的旧数字入口；这些入口用于回查，新链接使用案例的明确语义锚点。

网站和PDF分别由独立CI构建，避免整书排版阻塞在线阅读。当前PDF页码与图片嵌入位置在重新构建后更新；V4、V5及5.1的历史检查记录只能用于相应旧版，不能替代6.0的定位。
